## 原文（节选，保持原样）

选题二：基于 FPGA 的实时多音色合成电子乐器引擎

设计要求·基础要求：
1. **多维交互控制检测**：自主设计演奏交互形态，基于各类传感器实现演奏动作精准采集，支持选音、触发、拨弦、力度感应等操作，**具备至少 2 个独立可控维度**，交互逻辑灵敏稳定。
2. **FPGA 纯硬件实时音频合成**：完整音频通路全部基于 FPGA HDL 硬件逻辑实现，支持逐样本实时运算（波表采样 / 加法合成 / FM 调频 / 物理建模任选）；严格控制演奏延迟，**控制信号到音频输出总延迟 ≤ 10 ms**，杜绝软件串行运算滞后。
3. **合规实时发声与多复音**：基础复音数 **≥ 4**，支持四路及以上独立声部并发；所有输出音频由 FPGA 根据实时演奏指令**逐音、逐样本实时生成**，支持单音实时变调、ADSR 包络调控、多声部实时混音；**严禁直接播放预录 PCM 音频**。

拓展要求（加分）：
1. **超高规模并行合成**：复音数 **≥ 32**，或单音加法合成分量 **≥ 32 路**，或多条并行物理建模运算单元。
2. **多维表情控制与音频效果处理**：搭建 **≥ 3 维**演奏表情调控逻辑（力度动态、滑音、颤音等）；支持 **≥ 2 种**乐器音色自由切换；在 FPGA 硬件内部实现**混响、延迟、合唱**等数字音频效果。
3. **极致低延迟与实时视听反馈**：演奏延迟压缩至 **≤ 5 ms** 且确定性无抖动；基于 FPGA 硬件逻辑实时生成可视化反馈（LED 演奏指引、李萨如图形、实时频谱、波形显示等）。
4. **智能联动与脱机拓展**：脱机演奏 **LED 曲目指引**；可搭载蓝牙模块与手机 App 联动（在线曲谱下载、键位自定义、演奏录音回传等）。

评分规则：
- **振荡器统计**：独立发声单元 = 独立相位累加器 + 频率调控 + 包络控制的完整振荡器；单波表查表不计多谐波；加法合成按运算分量计；物理建模按并行弦/模态单元计。
- **吞吐量**：`同时活跃可闻独立振荡器总数 × 实际音频输出采样率`；过采样不叠加加分。
- **现场验证**：测试模式下输出多路不同频率音频，频谱可见对应数量的独立谱峰；并可用 RTL 佐证纯硬件实时合成、无预录音频播放。

板卡：Sipeed Tang 系列（Tang Nano 20K / Primer 25K / Mega 60K / 138K）。
