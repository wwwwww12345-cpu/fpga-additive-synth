## 0. 一句话

手机/实物键盘都可演奏；钢琴为加法合成（实测采样建模），吉他为 Karplus-Strong 物理建模；
有力度分层、触后颤音、滑音、混响、和弦、曲谱播放、OLED 相图、WS2812 灯带指引；
**实物矩阵键盘路径的演奏延迟约 1 ms**。

## 4. 接线

### 4.1 电源与共地

板子 USB 供电。**PCM5102、ADS1115、HC-04、OLED、灯带、键盘的 GND 必须全部与板子共地。**

### 4.2 蓝牙（HC-04，串口透传 115200 8N1）

| HC-04 | 板子 |
|---|---|
| VCC | 3V3 |
| TXD | **G2** |
| RXD | **G1** |
| GND | GND |

### 4.3 音频（PCM5102A）

| PCM5102 | 板子 | 说明 |
|---|---|---|
| VIN | 5V（按模块丝印） | |
| GND | GND | |
| SCK | **G5** | 固件恒 0 = 内部 PLL |
| BCK | **G8** | |
| LCK | **J5** | |
| DIN | **H7** | |
| OUT L/R | 音箱/耳机 | |

### 4.4 FSR 力度（ADS1115 + FSR402，**必接**，否则力度乱飘）

```
3V3 ──[ FSR402 ]──┬── AIN0 (模块 A0)
                  │
                [10k]
                  │
GND ──────────────┴── GND
```

| ADS1115 | 接法 |
|---|---|
| VDD | 3V3（不要接 5V） |
| GND | GND |
| SCL | **F1** |
| SDA | **A1** |
| **ADDR** | **GND**（地址 0x48） |
| AIN0 | FSR 分压节点 |
| AIN1~3 | 接 GND |

- **10k 下拉不能省**；不接 FSR 时也要保留 `AIN0—10k—GND`；
- 分压接反的症状：手离开也一直响 / 力度乱跳。

### 4.5 矩阵键盘（仅 02 / 03 / 04 需要）

16 键 4×4 模块，8 脚从左到右依次接：

| 模块脚 | 板子 | 角色 |
|---|---|---|
| 1 | **H1** | 行 1 |
| 2 | **K7** | 行 2 |
| 3 | **L7** | 行 3 |
| 4 | **L10** | 行 4 |
| 5 | **L9** | 列 1 |
| 6 | **J8** | 列 2 |
| 7 | **F7** | 列 3 |
| 8 | **J11** | 列 4 |

- 模块 **1~4 脚 = 行、5~8 脚 = 列**（队友实测 1/5 导通、1/6 导通得出）；接反的症状是**整行无音**或**整排音名平移**；
- **公头容易滑出**：嵌进去后热熔胶固定即可，**别焊死**（设备只有一个，焊死就不可换）；更稳是换杜邦公对母线；
- 列输入固件内部上拉；线长建议每列再并 **10k 到 3V3**；
- 弹和弦请每个键串 **1N4148**（否则三键 L 形会出现鬼键）；单音/双音可不串；
- 键位（只用自然音，第 8、16 键空）：

| 行 | 键1 | 键2 | 键3 | 键4 |
|---|---|---|---|---|
| 1 | **C4** | D4 | E4 | F4 |
| 2 | G4 | A4 | B4 | *(空)* |
| 3 | **C5** | D5 | E5 | F5 |
| 4 | G5 | A5 | B5 | *(空)* |

### 4.6 OLED（SSD1306/SH1106，128×64，四线 SPI）

| OLED | 板子 |
|---|---|
| SCL | **L5** |
| SDA（MOSI） | **K5** |
| RST | **K11** |
| D/C | **L11** |
| VCC / GND | 3V3 / GND |
| CS（若有） | GND |

固件按 **SH1106** 编译（`COL_OFF=2`）；SSD1306 屏一般也能亮，边缘可能差 2 列。

### 4.7 WS2812 灯带（可选）

DIN = **C2**，灯带 5V 独立供电并与板子共地。

### 4.8 其它

- `btn_test` = K4（测试模式选通，平时悬空）；
- `btn_rst` = H11（板上 USER_KEY，按下复位）。

## 5. 烧录与上电

1. Gowin Programmer 选对应 `.fs`，**SRAM 模式**（断电即失；要固化请用 Embed Flash）；
2. 烧完**按一下 H11 复位**（I2C 错误标志是粘滞的）；
3. 上电/复位时**手离开 FSR**；
4. 先听一声：手机连上点 PING 应回“FPGA 在线”；或直接按键盘键应出声。

## 6. 小程序（`miniprogram/`）

- 微信开发者工具导入 `miniprogram/hc04-ble`（appid `wxb21bcba86fcb9c32`，libVersion 3.4.0）；
- 首页 = 控制台：连接/PING、音域、和弦、音色、混响滑块、滑音滑块、曲谱下发与播放、日志；
- **弹琴页 = 横屏两个八度琴键，支持滑弦**（按下发 `0x87`，松开发 `0x88`）；
- 协议 v0.5：`0x89` 混响（0=干声，默认 32≈25%）、`0x8B` 滑音（0=关，越大越慢）。

## 7. 已知限制（重要）

1. **没有状态回读**：音域/和弦/音色/混响/滑音都只记在 FPGA 里，FPGA 复位后界面不会自动跟——以“复位后重新设一次”为准。
2. **02 的余量很薄（+0.659，CLS 92%）**：若上板出现偶发异常（个别音不响/卡顿），先重烧/复位；仍不稳定就换 03。
3. **02 里“BLE 事件在飞的同时按键盘”，可能吞掉那一下键盘音**（双源仲裁 race）。两路不要同时用即可；单路（只键盘 / 只手机）已验证正常。
4. **力度只有 4 层**（`v=code>>8`，层=`v>>5`），最轻那层在一般音量下偏轻；不碰 FSR 时回退 96（落 L3）。
   实测档位：L0 `23~31` / L1 `32~63` / L2 `64~95` / L3 `96~103`（满压只到 103）。
   **轻按实测 `7451~9229`（v=29~36）正好骑在 L0/L1 边界 32 上**，所以同一力度连按会跳层——这是"轻弹听不清 / 和最低层串"的根因，改法是抬 L0/L1 的表增益（见 `docs/待修清单_20261102.md` P1）。
5. 曲谱上限 512 条、`dur` 单位 10 ms（最大 1.27 s/条）。
6. 04 没有曲谱/和弦/OLED（为腾时序删掉）。

## 8. 常见故障

| 现象 | 先查 |
|---|---|
| 连不上 BLE | HC-04 是否 115200 8N1；TXD→G2 / RXD→G1 是否接反；模块是否被别的设备占用 |
| 有声但一直响/手离开也响 | FSR 分压接反或缺 10k 下拉 |
| 力度永远一样 | ADS1115 的 ADDR 是否接 GND、F1/A1 是否通、共地 |
| 键盘按键错音 | 行/列 8 根线的顺序是否按 §4.5；模块是 4×4 矩阵（不是编码输出） |
| 多键同按出现“幽灵音” | 没串 1N4148（鬼键） |
| OLED 不亮/花屏 | SH1106/SSD1306 差异、RST 是否被接死、VCC |
| 偶发不发声 | 02 版时序薄，换 03 或重烧 |

## 9. 验收证据（本轮仿真）

- 矩阵键盘模块：16 键逐键 + 空键 + 双键 + 3 ms 去抖 + 力度，**122/122 通过**；
- 整机（02）：只 BLE / 只矩阵 均通过；“同时发”1 条失败（见 §7.3）；
- BLE 协议：`tb_ble_e2e` 52 项、`tb_ble_fsr_vel` 10 项、和弦事件序 3on→3off→3on→3off；
- 协议自测：`protocol.selfTest` 33 项；
- 逐位回归：吉他琴体 2050 样本、KS 400 样本、钢琴引擎 4097 样本，mismatch = 0。
