## 3. 未完成 / 未验证（必须如实写进报告）

1. **混响湿声在板上不可闻**：07 固件（v33）在真实板子上听不到湿声；探针 09（只放湿声）完全静音。
   RTL 逻辑与仿真通过，但板上行为矛盾。下一步是 168 ms 回声 + 1:1 湿声的判决实验（未做）。
   **不要写"混响正常工作"。**
2. **演奏延迟**：矩阵键盘路径"按下到出声约 1 ms"是项目内测口径（键盘扫描 80 µs + 事件握手 + 引擎起振），
   没有做过示波器/逻辑分析仪的正式测量；BLE 路径受连接间隔与 App 排队影响，量级几十 ms，**未测**。
   赛题硬指标 ≤10 ms 的"满足"只对**直连键盘路径**成立，报告里要写清前提。
3. **采样率**：48.828125 kHz 是设计值（50 MHz ÷ 1024，整数分频），**不是 48.000 kHz**；
   相对 48 kHz 偏 **+29.6 音分**。音高表已按该采样率重算，所以听感音高正确。
4. **无状态回读**（`0xA0` 未实现）：复位后小程序界面与 FPGA 内部状态可能不一致。
5. **双源同时输入**未做长时间 soak；07 已修仲裁逻辑，但演示建议单路操作。
6. 混响/延迟/合唱三种效果中**只做了混响**；频谱/波形显示未做（只有李萨如）。
