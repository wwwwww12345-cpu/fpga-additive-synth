> 板卡：Sipeed Tang Primer 25K / Gowin **GW5A-25A**，50 MHz。

> 烧录：Gowin Programmer → 选 `.fs` → SRAM 模式 → 烧完按 H11 复位（上电时手离 FSR）。

## 1. 推荐顺序

| 场景 | 用哪个 |
|---|---|
| 现场演示（键盘 + 手机 + 全套功能） | **07**（余量薄，先连弹 10 分钟确认稳定） |
| 演示兜底 / 只弹键盘求稳 | **03**（钢琴 only，SETUP +0.966） |
| 没有实物键盘，用手机弹 | **01** |
| 键盘 + 吉他、不要 OLED | **04** |
| 07 出偶发异常时的回退 | **06**（同功能，混响旧公式）或 **03** |

## 3. 版本关系

- **06 = 02 的源码重编**：双源仲裁修复（键盘与 BLE 同拍不再丢事件）+ 曲谱同音重触发修复
  + 吉他延迟线地址改为每声部一个指针（`gtr_ks_engine` v32）。代价是 SETUP 从 +0.659 掉到 +0.202。
- **07 = 06 + 混响湿声公式修正**（`rvb_mono` / `top.v` v33）：原来湿声输出里混进了干声，顶层又加一次干声，
  导致 `0x89` 实际是"干声增益旋钮"。07 改成湿声单独输出。
  **注意：07 在板上仍然听不到湿声**（见 README §7 已知限制），`0x89` 的寄存器行为已修正，但效果未达标。
- **12 = v35 混响最小结构**（诊断固件）：把混响核换成最简结构，用来判断"板上 `rvb_y` 是否恒 0"。
  **不要用于演示**（回声间隔约 42 ms，与钢琴余音重叠，听感只是"变厚/变毛"）。
- 08/09/10/11 未随包：08/09/11 是一次性探针，10 是 v34 长混响实验版（SETUP +0.033，不演示）。
